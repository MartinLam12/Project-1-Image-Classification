# Project 1 — Image Classification

Compares six dense neural networks (shallow and deep, each with ReLU, Sigmoid and Tanh) on the Fashion MNIST dataset.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MartinLam12/project-1-image-classification/blob/main/project1.ipynb)

## Run locally
1. Clone this repo: `git clone https://github.com/MartinLam12/Project-1-Image-Classification`
2. Create the environment: `conda env create -f requirements.yml`
3. Activate it: `conda activate project1`
4. Start Jupyter: `jupyter notebook project1.ipynb`
5. Choose Run all. The dataset downloads automatically.
